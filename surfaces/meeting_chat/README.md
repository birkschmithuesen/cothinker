# Meeting chat

Participants type a task for the agent ("compare X and Y as an interactive page on the stage") and read its answer
(issue #208, ADR 0027). A surface of the participant contract (ADR 0019): `GET /snapshot`, `GET /events`,
`POST /actions`, nothing else. Served at `/chat/` in a deployment (ADR 0020 as amended by ADR 0027); the operator
console embeds it with `?chat=<same-origin URL of this page>`.

Open it against the fixture server: `python -m surfaces.contract --fixtures meeting --cors-origin <origin>`, then
`index.html?api=http://127.0.0.1:8000/`. Look comes only from `tokens.css`, generated by
`python -m surfaces.design.build --out-dir surfaces/meeting_chat` (ADR 0023); strings live in `texts.js`.
