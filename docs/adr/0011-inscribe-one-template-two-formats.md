# ADR 0011: InScribe: one template, long and one-day format

- **Status:** accepted — see ADR 0018 for the final surface names
- **Date:** 2026-11-20

## Context

Source: concept-round decision log 2026-11-20, entries 4, 5, 6 and 8.

Two web apps exist: one guides a group autonomously through 6–7 phases over several days (entry 4), the other runs a one-day workshop with fewer phases (entry 5). Both share the structure interview → condensation → writing text (entry 6). The one-day workshop is InScribe in a shorter format (entry 8).

## Decision

InScribe is **one template** with two formats: the **long format** (6–7 phases, the InScribe web app) and the **one-day format** (fewer phases, the workshop web app). Both formats use the same blocks; they differ in phase definitions and surfaces.

## Consequences

- The phase definitions of both formats have to be written out in detail; that is an open decision.
- Blocks the one-day format built (interview round, setting round, contrast pairs, poster, write text) and those the long format built (piece model, dramaturgy checks, quote anchoring) are merged per function, not per format.
- The final names of the two web apps are open.

## Rejected options

- Two separate methods: entry 8 decided they are one.
- A group-process method between them: dropped by entry 8.
