# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Instead,
use GitHub's private vulnerability reporting for this repository (the
"Report a vulnerability" button under the Security tab) with a
description of the issue and, if possible, steps to reproduce it.

## What to expect

This is a small project without a dedicated security team or a fixed
response SLA. Reports are handled on a best-effort basis: expect an
acknowledgement, and a fix or mitigation once the report is understood,
but no guaranteed timeline.

## Scope

This covers the CoThinker codebase in this repository. Vendored
third-party code (listed in `THIRD_PARTY.md`) should be reported
upstream as well, since a fix here cannot outrun the original project.
